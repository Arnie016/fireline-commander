# Evidence

The `demo-evidence/` folder stores the reviewable evidence bundle.

## Files

| File | Purpose |
| --- | --- |
| `demo-evidence/drill_knowledge.snapshot.json` | Source drill knowledge records |
| `demo-evidence/retrievals.json` | Generated retrieval outputs for the core scenarios |
| `demo-evidence/retrieval-report.md` | Human-readable evidence report |
| `demo-evidence/manifest.json` | Metadata for the evidence bundle |

## Regenerate

```bash
npm run hackathon:final
```

The archive is intentionally clear when it is using local demo evidence instead of a live hosted deployment.
