# Demo

## 3-Minute Path

1. Open the app.
2. Start `Fireline school`.
3. Show the first-person route cockpit.
4. Pick a route rule.
5. Show the decision consequence.
6. Point to `Mission Intelligence`.
7. End on the handoff artifact.
